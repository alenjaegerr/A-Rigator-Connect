A-RIGATOR CLEAN ASSET LIBRARY

This package replaces the noisy traced SVGs.

Each SVG is a clean SVG container embedding a transparent PNG crop from the original supplied artwork.
This preserves the original illustration's exact colors, anti-aliasing, outlines and details without introducing tracing artifacts.

IMPORTANT:
- These SVGs are scalable containers, but the embedded illustration remains raster artwork.
- They are suitable for preserving the mascot appearance in layouts and app prototypes.
- They are NOT yet independently editable vector paths.
- For independently animatable body parts, eyes, mouth, goggles and accessories, the mascot must be manually redrawn as layered vector artwork.
- White regions enclosed by the character (eyes, teeth, highlights) are preserved; only outer white background is removed.
- Use the standalone PNGs when the app framework handles raster assets more reliably; use SVG wrappers where SVG import is convenient.
